# Observational Real-Trace Replay

This experiment evaluates the locked-day verifier profiles against the measured MIT SuperCloud scheduler/DCGM execution trace. No event-response optimization is used to construct the target. The panel reports trace-alignment metrics and is explicitly observational; it is not interpreted as a causal intervention estimate.

The run writes the complete daily panel, slot-level overlay, summary statistics, metadata, checkpoints, and English figures under this directory.
