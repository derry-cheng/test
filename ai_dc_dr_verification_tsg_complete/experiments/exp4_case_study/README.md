# Experiment 4 — Spatial Case Study

Run with `python run.py` or `./run_all.sh --stage exp4`. The day is selected by the
pre-declared maximum gross-minus-net spatial offset rule, then reported at all four
nodes for the full day. `results/intermediate/case_selection_candidates.csv`
records the selection statistic for every locked test day; `results/final/`
contains the selected full-day trace, nodal summary, and metadata.
