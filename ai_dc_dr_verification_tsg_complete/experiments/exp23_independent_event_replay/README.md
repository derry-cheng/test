# Experiment 23: independent controlled-event replay

This panel evaluates the locked verifier against a predeclared event tariff
applied to a gate-masked submitted-job ledger. The event meter is generated by
an independently parameterized workload LP with a predeclared event-service
floor and no statistical target, risk envelope, candidate weights, or verifier
output as an input. The panel therefore tests the information boundary and
response certificate under a structurally distinct controlled intervention. It
is explicitly not a field estimate of a utility treatment effect because the
public traces do not contain an event label.

The controlled policy uses a predeclared tariff pair and a 5-MWh event-service
floor distinct from the gate response, so the event meter is not a copy of the
committed response objective. The run fails closed if the two solved response
trajectories collapse to machine precision, preventing an independence claim
based only on different labels.
The final outputs are `results/final/independent_event_replay_daily.csv`,
`independent_event_replay_summary.csv`,
`independent_event_profiles.npz`, and the publication figure in `figures/`.
The run is bounded by `independent_event_workers` in the frozen configuration
and reports progress through the unified pipeline manifest.
